# Hug Machine — love-hug

A hug button for Mena. Squeeze it for a quick burst; **hold it down** for a
real hug — warmth fills for eight full seconds and the machine says the big
line. Every squeeze is counted (localStorage only).

Live: https://menaammarpro.github.io/love-hug/

## Send a hug

`Copy a hug link` puts `?hug=1` on the URL. Whoever opens that link sees
"**Ammar sent you a hug ♥**" with the machine already pulsing — press it to
send one back.

## Storage key

- `mena-hug` — `{ squeezes, longest, last }`
